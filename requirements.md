# Requirements — LOOM Demo Video (BITSoM Builders PitchFest 2026)

## 1. Purpose
Produce a short demo video, and the on-screen script page that supports recording it, explaining LOOM's four agents — WARP, WEFT, HEDDLE, SELVAGE — to a PitchFest judging panel evaluating the **AI Innovation** track: *"push technical boundaries with multi-agent systems and software automation; engineer intelligent agents that accelerate R&D, code synthesis, workflow orchestration, or creative execution."*

## 2. Audience
- BITSoM Builders PitchFest 2026 judges (Stage 1: Concept & Core Architecture)
- Anyone the prototype link is shared with afterward

## 3. Core message
LOOM is not a single generic agent — it is four agents, each scoped to exactly one of the four capabilities named in the track prompt, and each named after the loom part that performs the equivalent physical role:

| Agent | Loom role | Track capability |
|---|---|---|
| WARP | Lengthwise threads mounted first; the structural foundation | R&D acceleration |
| WEFT | Cross-thread woven over/under the warp | Code synthesis |
| HEDDLE | Frame that lifts individual threads to control the pattern | Workflow orchestration |
| SELVAGE | Self-finished edge that stops fabric from unraveling | Creative execution |

## 4. Format requirements
- Runtime target: **~2 minutes** (2:00–2:15)
- Format: two-column AV script (VISUAL / AUDIO) per scene, with timecodes
- Must include: cold open, problem statement, solution reveal, one scene per agent, a live-proof scene, and an ask/CTA scene
- Delivered as the standard four-file bundle: `index.html`, `requirements.md`, `tasks.md`, `readme.md`

## 5. Design requirements
- Visual language drawn from the loom/weaving metaphor itself (warp threads, a weaving weft, brass/rust thread colors) rather than generic AI/dashboard styling
- Dark, polished single-file HTML with one deliberate animated moment (thread-weave forming the wordmark), no build step, no backend
- Legible as both a **screen record source** (judges see it) and a **teleprompter/shot list** (presenter reads from it while recording)

## 6. Production requirements (not covered by index.html)
- Voiceover recording of the AUDIO column, scene by scene
- Screen-recording of the live prototype for the "proof" scene
- Final GitHub repo URL swapped into the proof-scene links before recording
- Export as MP4 for PitchFest submission portal

## 7. Success criteria
- A judge can, within 2 minutes, state what each of the four agents does and why the naming isn't decorative
- Video ends on a concrete, time-bound ask (Vertex incubator seat + 60-day pilot commitment)
