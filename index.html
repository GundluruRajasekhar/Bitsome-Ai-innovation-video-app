THE IDEA

A loom doesn't have one thread. It has a system for many.

Most multi-agent demos show agents that talk about working together. LOOM's four agents are named after the physical parts that make weaving possible — because each one maps, one-to-one, onto a stage of real engineering work.

The problem we're pitching against

Generic agent stacks blur research, coding, sequencing, and polish into one undifferentiated "agent" that does all four badly. Handoffs get faked in demos with a hardcoded transition.

What LOOM does instead

Four distinct agents, each scoped to one job the brief names explicitly — R&D, code synthesis, workflow orchestration, creative execution — passing real context to each other in a visible sequence.
