# LOOM — Demo Video Script

Supporting bundle for LOOM's submission to **BITSoM Builders PitchFest 2026**, AI Innovation track.

## What this is
LOOM is a multi-agent orchestration engine built for the track prompt: *push technical boundaries with multi-agent systems and software automation; engineer intelligent agents that accelerate R&D, code synthesis, workflow orchestration, or creative execution.*

Its four agents are named after loom parts, and each name maps directly onto one of those four capabilities:

- **WARP** — R&D acceleration (lays the structural plan first)
- **WEFT** — code synthesis (weaves the plan into working code)
- **HEDDLE** — workflow orchestration (sequences which agent acts next)
- **SELVAGE** — creative execution (finishes and polishes the output)

## How to use `index.html`
1. Open it in a browser — the hero section shows the opening weave-in animation you can screen-record directly.
2. Scroll to the **script** section and use it as a teleprompter: read the AUDIO column aloud while the VISUAL column tells you what should be on screen.
3. Before recording the "proof" scene, replace the placeholder GitHub link in the **links for the proof scene** section with your real repo URL.
4. Screen-record the live prototype for that same scene: https://gundlururajasekhar.github.io/Multi-agent-loom-app/
